# 多人分帳捷徑

跟朋友吃飯、出遊，不用再事後對帳。

在 iPhone 上執行捷徑，選付款人、分帳方式和要分錢的人，確認分帳預覽後，每個人欠多少會自動寫進共用的 Google 試算表。

## 功能

- **三種分帳方式**
  - 單人：某個人幫另一個人付錢
  - 均攤：總金額由勾選的人平分
  - 不同金額：每個人分別輸入自己的金額
- **分帳預覽**：送出前列出付款人、欠款人和每人金額，確認後才寫入
- **自動寫入試算表**：每個欠款人寫成一列，付款人本人會自動排除
- **金額以「分」計算**：避免 1/3 這類除不盡時出現浮點誤差

## 運作方式

```
iPhone 捷徑  ──(POST JSON)──▶  Google Apps Script  ──▶  Google 試算表
```

捷徑送出的資料：

```json
{
  "date": "2026-10-10",
  "item": "晚餐",
  "payer": "成員1",
  "note": "",
  "split": "{\"person\":\"成員2\",\"amount\":183.33}\n{\"person\":\"成員3\",\"amount\":183.33}"
}
```

`split` 支援多種格式：JSON 陣列、單一物件、每行一筆 JSON，或純文字「名字 金額」。這是因為 Apple 捷徑組 JSON 很不穩定，接收端要能吃下各種寫法。

## 自己架一套

### 1. 準備試算表

建立一份 Google 試算表，新增一個名為 `transactions` 的工作表，第一列放標題：

| 日期 | 品項 | 付款人 | 欠款人 | 金額 | 備註 |
|---|---|---|---|---|---|

### 2. 部署 Apps Script

1. 在試算表點選 **擴充功能 → Apps Script**
2. 把 `Code.gs` 的內容整個貼上並儲存
3. 點右上角 **部署 → 新增部署作業**，類型選 **網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按「部署」，複製產生的網址

> 這個網址等於是試算表的寫入入口，**不要公開分享**，也不要 commit 進 repo。

### 3. 安裝捷徑

1. 開啟捷徑分享連結：`https://www.icloud.com/shortcuts/bef0f0a2c1ee459ab9a55f6b0f1cbc95`
2. 安裝時會詢問：
   - **網頁應用程式網址**：貼上步驟 2 的網址
3. 打開捷徑，把成員名單改成你們自己的名字
